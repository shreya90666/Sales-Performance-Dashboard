# Sales Performance Dashboard

This project analyzes retail sales data using Python, Oracle SQL, and Power BI.

## Tools Used
- **Python (Google Colab):** Data cleaning and analysis using pandas
- **Oracle SQL:** Creating tables, storing data, and running SQL queries
- **Power BI:** Creating an interactive sales dashboard

## Project Features
- Data cleaning and validation
- Sales and profit analysis
- Sales comparison by region and category
- Monthly sales trends
- Top 10 products by sales
- Interactive filters and drill-down

## Dataset
The project uses the Sample Superstore dataset containing 9,994 records.

## Files Included
- Python notebook
- Cleaned dataset and data quality report
- Oracle SQL script
- Power BI dashboard
- Star-schema diagram
- Project report

## Conclusion
This project helps understand sales performance, identify top-selling products, and compare sales across different regions and categories.
